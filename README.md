# GEXX — Personal Website

A responsive personal site for Cybersecurity, Linux, Aqidah and ARK. One editorial layout and a monochrome palette connect the topics as parts of one identity.

## Run locally

Open `index.html` in a browser or serve this directory with any static file server. There is no build step, backend or account. Google Fonts are optional; system font fallbacks are included.

## Design notes

- Typography, spacing and fine rules carry the visual design; the site has no hero illustration or decorative color effects.
- The mobile navigation collapses to a full-screen text menu. Responsive layouts use 900px, 680px and 360px breakpoints.
- Scroll reveals and navigation transitions are subtle. Reduced-motion preferences disable transitions and reveal delays.
- The Aqidah index contains only Quran, Hadith, Knowledge and Notes. It does not invent religious claims or quotations.
- The ARK section separates personal topics from external game references.
