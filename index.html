01 / Threat library

KENNE DEINEN
GEGNER.

„Virus“ wird oft als Sammelbegriff benutzt. Technisch gibt es mehrere Arten von Malware – sie unterscheiden sich darin, wie sie eindringen, sich verbreiten und Schaden anrichten.

THREAT TYPE / 01

Computervirus

Hängt sich an Dateien oder Programme und verbreitet sich, wenn infizierter Code ausgeführt wird. Nicht jeder Virus verbreitet sich automatisch übers Netzwerk.

Datei-Infektion
THREAT TYPE / 02

Wurm

Kann sich selbstständig über Systeme oder Netzwerke ausbreiten, oft indem Schwachstellen oder unsichere Konfigurationen ausgenutzt werden.

Selbstverbreitung
THREAT TYPE / 03

Trojaner

Gibt sich als legitime Anwendung oder Datei aus. Beim Start kann er weitere Schadfunktionen nachladen oder Angreifern Zugriff ermöglichen.

Tarnung
THREAT TYPE / 04

Ransomware

Verschlüsselt oft Dateien oder sperrt Systeme und fordert Lösegeld. Offline-Backups helfen, die Folgen eines Angriffs zu begrenzen.

Datenverlust
THREAT TYPE / 05

Spyware & Stealer

Versucht Informationen wie Zugangsdaten, Browserdaten oder andere persönliche Informationen zu sammeln und zu stehlen.

Datendiebstahl
THREAT TYPE / 06

Rootkit & Botnet

Ein Rootkit versucht seine Präsenz zu verbergen; ein Botnet verbindet kompromittierte Geräte, die aus der Ferne missbraucht werden können.

Versteckter Zugriff

03 / Defense protocol

SICHER BLEIBEN.
JEDEN TAG.

Kein einzelnes Tool fängt alles ab. Die besten Grundlagen sind aktuelle Software, vorsichtiges Verhalten, sichere Konten und Backups. Diese Basics empfiehlt auch die US-Cybersicherheitsbehörde CISA.

STEP 01

Updates installieren

Betriebssystem, Browser und Programme aktuell halten. Updates möglichst aus offiziellen Quellen beziehen.

STEP 02

Absender prüfen

Unerwartete Anhänge und Login-Links hinterfragen. Lieber direkt die offizielle Website öffnen.

STEP 03

Schutz aktiv lassen

Echtzeitschutz und Firewall nicht abschalten, um eine unbekannte Datei „mal kurz“ zu testen.

STEP 04

Backups machen

Wichtige Daten zusätzlich sichern. Mindestens eine Sicherung sollte nicht ständig mit dem PC verbunden sein.

04 / Antivirus testen

SICHER TESTEN.
OHNE ECHTEN VIRUS.

Für einen kontrollierten Test gibt es die EICAR-Testdatei. Sie enthält keinen echten Virus, ist aber speziell dafür entwickelt, dass kompatible Antivirenprogramme eine Erkennung melden.

Standard-Testdatei

EICAR Anti-Malware Testfile

Nutze ausschließlich die offizielle Quelle und lies die dortigen Hinweise. Je nach Schutzsoftware kann die Datei direkt blockiert oder in Quarantäne verschoben werden. Das ist bei einem solchen Test erwartbar.

Die EICAR-Datei ist ein Testsignal, kein echter Malware-Test und kein Nachweis, dass dein System gegen echte Schadsoftware geschützt ist. Schutzsoftware niemals deaktivieren, um sie herunterzuladen.

07 / Quick answers

MYTHEN VS.
FAKTEN.

Die wichtigsten Missverständnisse rund um Viren in aller Kürze.

Kann ein Virus allein durch das Öffnen einer Website kommen?

Das bloße Besuchen einer Website führt nicht automatisch zu einer Infektion. Trotzdem können manipulierte Seiten, Browser-Schwachstellen, betrügerische Downloads oder gefälschte Login-Seiten Risiken darstellen. Browser aktuell halten und verdächtige Downloads vermeiden.

Bedeutet „0 Erkennungen“, dass eine Datei sicher ist?

Nein. Scanner können neue, maßgeschneiderte oder gut getarnte Bedrohungen übersehen. Ergebnisse sind Hinweise und müssen im Kontext betrachtet werden; auch Fehlalarme kommen vor.

Ist jede Malware ein Computervirus?

Nein. Malware ist der Oberbegriff für schädliche Software. Viren, Würmer, Trojaner, Ransomware und Spyware sind unterschiedliche Kategorien mit unterschiedlichen Eigenschaften.

Was soll ich tun, wenn ich einen echten Verdacht habe?

Öffne die verdächtige Datei nicht weiter. Bei einem möglichen aktiven Vorfall trenne das betroffene Gerät bei Bedarf vom Netzwerk, nutze die Sicherheitsfunktion des installierten Schutzprogramms und hole vertrauenswürdige Hilfe. Ändere Passwörter von einem sauberen Gerät, wenn Zugangsdaten betroffen sein könnten.
