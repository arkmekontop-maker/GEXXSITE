01 — The method

Research is a process, not a search bar.

Open-source intelligence (OSINT) means extracting and assessing information from publicly accessible sources. Good work keeps facts, interpretation and unknowns separate. It does not mean breaking into accounts or collecting everything about a person.

GEXX principle / 001
“A strong conclusion should survive someone else checking your sources.”

Keep a trail: what you looked at, when you saw it, where it came from, what it proves — and what it does not prove.

↗

Start with a question. End with evidence.

Define the question before collecting material. Prefer primary sources, record dates and context, corroborate key claims independently, and stop when the research question has been answered.

STEP 01

Scope

Write one specific question, the time period and the information you genuinely need.

STEP 02

Collect

Use lawful public sources, official records, published reports and archived pages.

STEP 03

Verify

Check the original source, author, date, context and independent corroboration.

STEP 04

Document

Save relevant URLs, timestamps, quotations and hashes when they help preserve integrity.

STEP 05

Qualify

Label what is confirmed, what is inferred and what remains unknown.

Practical rule: screenshots and search snippets are leads, not proof on their own. A page can be edited, a date can be misleading, an image can be reused, and two sites can simply repeat the same original claim.

03 — Linux workbench

Useful tools start with understanding the output.

Linux is a flexible environment for scripting, inspecting files and organising research. Kali Linux is based on Debian and designed for penetration testing and security auditing; it is not a magic shortcut or a requirement for OSINT.

FIELD GUIDE / LINUX

Small commands.
Reliable habits.

Begin with commands that explain your environment and help you inspect files. Work on files you own or have permission to analyse. Verify downloads from official sources and avoid running unknown scripts with elevated privileges.

Understand every command before you run it.

Kali documentation ↗Verify downloads ↗
Terminal notes / safe examplesLINUX
$ uname -a
# Show kernel and system information
Linux hostname ... x86_64 GNU/Linux
$ file sample.pdf
# Inspect a file's detected type
sample.pdf: PDF document
$ sha256sum sample.pdf
# Calculate a file's SHA-256 hash
e3b0... sample.pdf
Examples only. Replace sample.pdf with a file you trust and have permission to inspect.
What these commands do: uname -a prints system and kernel information; file describes the detected format; sha256sum computes a hash to compare file identity. A hash can show that two files differ, but does not establish that either file is safe.
04 — Official investigation resources

FBI and public records: go straight to the source.

This section links to publicly available U.S. government resources for cybercrime reporting and published case information. These links are for reference and learning — this website is not an FBI service, does not represent the Bureau and cannot submit tips on your behalf.

U.S. Federal Bureau of Investigation

Public cybercrime information

The FBI publishes public information on cyber investigations and wanted subjects. Read agency announcements carefully, distinguish allegations from proven findings, and use the original page rather than reposted screenshots.

Official reporting channels

Report suspected cybercrime

The FBI's public tip page directs reports of cyber-enabled crime to the Internet Crime Complaint Center (IC3). For immediate danger in the U.S., the FBI says to contact emergency services rather than use the web form.
