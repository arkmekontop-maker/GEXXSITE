Example terminalREAD-ONLY EXAMPLES
$ sha256sum sample.pdf# Calculate a local file hash
$ file sample.pdf# Identify the detected file type
$ uname -a# Print system/kernel information

A hash helps compare file identity; it does not tell you whether a file is safe. Use commands on files you own or are authorised to inspect. Don't run unknown scripts with elevated privileges.

About / 06

GEXX Fieldnotes

A personal learning workspace for open-source research, Linux and digital investigation methods. Designed for useful notes, reproducible steps and clear boundaries.

Principle 01

Evidence over aesthetics.

Tools are useful only when the result can be explained. This project promotes source checks, context, careful wording and awareness of uncertainty.

Principle 02

Curiosity with boundaries.

Research public information for a legitimate purpose. Respect privacy, avoid intrusive profiling and use security tools only on systems or data you own or are authorised to assess.

Independence

Not an official agency portal.

GEXX is not affiliated with the FBI, a government agency or the organisations linked here. External references are provided to help users reach primary information.
